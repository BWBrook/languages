# Lesson 01: Population Growth

## Exercise

Each language implements the same tiny task:

- start with a population of `120`,
- apply annual growth of `7%`,
- print the population from year `0` to year `5`.

## Why This Exercise

It is small, but it reveals a lot:

- variable assignment,
- function definition,
- loops,
- numeric formatting,
- how "heavy" or "light" the language feels for a basic scientific calculation.

## What To Look For

When comparing implementations, pay attention to:

- how much setup is required before real work starts,
- whether types are explicit or implicit,
- whether the syntax feels loose, strict, or ceremonial,
- how readable the loop and formatting logic feel,
- whether the language encourages decomposition into functions.

## Suggested Reading Order

1. `C`
   - good baseline for explicitness and old-school familiarity.
2. `BASIC`
   - good reminder of what a minimal, older home-computer language makes awkward or easy.
3. `Python`
   - familiar control case.
4. `JavaScript`
   - compare dynamic scripting style with Python.
5. `Ruby`, `Perl`, `Tcl`
   - three very different answers to "dynamic interpreted language".
6. `Java`
   - compare ceremony and static structure.
7. `Swift`
   - compare a modern static compiled language with safer defaults.

## Later Extensions

This same lesson can evolve into:

- adding carrying capacity,
- reading parameters from a file,
- turning the projection into a reusable module,
- plotting the trajectory,
- measuring performance across implementations.
