# R

`R` is a familiar anchor. We will use it to compare languages that are more general-purpose or more strongly typed against a language designed around data analysis and statistics.

Good at:

- statistics,
- data analysis,
- plotting and exploratory workflows.

Less good at:

- large general-purpose software systems,
- some performance-sensitive patterns when written naively.

Run:

- `make run LANGUAGE=r DEMO=hello`
- `make run LANGUAGE=r DEMO=population_growth`
