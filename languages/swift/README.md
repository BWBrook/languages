# Swift

`Swift` is a good modern compiled counterpoint to `C` and `Java`: safer than the former, less ceremonial than the latter, and especially relevant on Apple systems.

Good at:

- performance with safety,
- strong typing,
- modern language features on Apple platforms.

Less good at:

- tiny throwaway scripts compared with looser interpreted languages,
- ecosystem portability outside its strongest domains.

Run:

- `make run LANGUAGE=swift DEMO=hello`
- `make run LANGUAGE=swift DEMO=population_growth`
