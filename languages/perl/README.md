# Perl

`Perl` is worth keeping in the lab because it remains one of the classic text-processing languages, and because its strengths and weaknesses are both very visible.

Good at:

- regex-heavy transformations,
- command-line text work,
- concise scripts.

Less good at:

- readability once code gets dense,
- keeping style consistent across authors.

Run:

- `make run LANGUAGE=perl DEMO=hello`
- `make run LANGUAGE=perl DEMO=population_growth`
