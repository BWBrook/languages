# Tcl

`Tcl` is here because it offers a very different mental model from most current mainstream languages. That difference makes it educational.

Good at:

- embeddable scripting,
- glue code,
- simple command-oriented composition.

Less good at:

- mainstream ecosystem reach,
- familiarity if you expect more conventional expression syntax.

Run:

- `make run LANGUAGE=tcl DEMO=hello`
- `make run LANGUAGE=tcl DEMO=population_growth`
