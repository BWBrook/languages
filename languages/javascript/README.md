# JavaScript

`JavaScript` matters because it is everywhere, and because it demonstrates what happens when a language evolves under massive real-world pressure.

Good at:

- ubiquitous scripting,
- asynchronous and event-driven code,
- full-stack web work.

Less good at:

- conceptual neatness,
- avoiding historical quirks.

Run:

- `make run LANGUAGE=javascript DEMO=hello`
- `make run LANGUAGE=javascript DEMO=population_growth`
