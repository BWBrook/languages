# C

`C` is here as the old-school baseline: explicit, close to the machine, and still one of the best ways to understand what higher-level languages are buying you.

Good at:

- control over memory and data layout,
- performance-sensitive code,
- learning fundamentals.

Less good at:

- safety by default,
- quick exploratory scripting,
- reducing incidental complexity.

Run:

- `make run LANGUAGE=c DEMO=hello`
- `make run LANGUAGE=c DEMO=population_growth`
