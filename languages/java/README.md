# Java

`Java` earns a place here because it represents a language where ecosystem, tooling, and maintainability often matter more than syntactic lightness.

Good at:

- large applications,
- stable tooling and library ecosystems,
- strongly structured codebases.

Less good at:

- terseness,
- low-friction experimentation for tiny tasks.

Run:

- `make run LANGUAGE=java DEMO=hello`
- `make run LANGUAGE=java DEMO=population_growth`
