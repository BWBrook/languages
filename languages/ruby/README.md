# Ruby

`Ruby` is here because it shows a very different dynamic-language personality from both `Python` and `JavaScript`: more object-oriented, more syntactically expressive, and often more conversational in style.

Good at:

- elegant scripting,
- internal DSLs,
- readable object-oriented code.

Less good at:

- raw speed,
- broad default modern availability on this machine.

Run:

- `make run LANGUAGE=ruby DEMO=hello`
- `make run LANGUAGE=ruby DEMO=population_growth`
