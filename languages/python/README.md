# Python

`Python` is a familiar anchor here. We will often use it as the "clear baseline" when another language feels odd.

Good at:

- readable general-purpose scripting,
- scientific and data workflows,
- fast iteration.

Less good at:

- raw performance,
- strong runtime guarantees unless you layer on more tooling.

Run:

- `make run LANGUAGE=python DEMO=hello`
- `make run LANGUAGE=python DEMO=population_growth`
